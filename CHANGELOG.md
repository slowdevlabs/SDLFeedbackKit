# Changelog

## 0.1.0

- Initial public release of SDLFeedbackKit.
- Swift Package scaffold with iOS and macOS support.
- Public core models, payload contract, validation, and transport protocol.
- Adaptive attachment optimization with 1,000,000 byte default final limit.
- SwiftUI feedback form UI with localized strings.
- Native attachment pickers for iOS and macOS.
- Example host apps for iOS and macOS.
